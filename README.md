This project was created with sole purpose of completion of Capstone as part of the requirement for PostGraduate Diploma in Artificial Intelligence and Machine Learning Certification at Asian Institute of Management
Project domain covers Clustering Option (Unsupervised) using Customer Segmentation public data from Kaggle (Source: https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis).  

Topics covered include: 1.	Problem Understanding & Framing, 2.	Data Collection & Understanding, 3.	Data Preprocessing, Applied EDA & Feature Engineering, 4.	Model Implementation, and 5. Critical Thinking
